Tohotopia LLM AI v0.2.0
========================

Steam Workshop item: 3843427412 ("LLM AI in Tohotopia")
Requires: TOHOTOPIA game 0.8.5d, TH1 Mod Loader 0.8.031+
  https://steamcommunity.com/sharedfiles/filedetails/?id=3829555573

This is the first Workshop release and a full rework of the mod:

* Moved from BepInEx to the TH1 code mod loader; the mod now runs fully
  headless with no BepInEx/Unity dependencies.
* AgentHost is a standalone NativeAOT local service; no .NET install needed.
* The settings app is a standalone Avalonia control panel
  (TH1LLMBattlePanel.exe). The tray mode was removed: closing the window
  exits the panel, and first launch creates a "TOHOTOPIA LLM AI 控制面板"
  desktop shortcut automatically.
* Model takeover works in normal Steam lobbies via native AI seats
  (up to 4 seats, per-seat provider/model/reasoning).
* Per-match state isolation, ordered action plans, ally/team chat
  communication and out-of-turn coordination.
* Settings, credentials and logs live in %LOCALAPPDATA%\TohotopiaLLM
  (DPAPI-protected), separate from the Workshop package; first start
  migrates legacy BepInEx runtime data.
